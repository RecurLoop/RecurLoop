```recurloop
http "address" port {
    METHOD "path" -> handler
    ...
}
```

Starts an HTTP server with a route table. Handlers have signature `(request:Http:Request*, response:Http:Response*) -> void`; a handler may also be an inline `fn`. Add `once` after `http` to serve one request.

**Example**

```recurloop
http "127.0.0.1" 8080 {
    GET "/" -> home
    POST "/echo" -> echo
}
```
