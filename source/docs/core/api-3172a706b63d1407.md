Execute a source file here.

```recurloop
include "path.rl"
```

Executes another source file in the current context. Relative paths are resolved from the including file.

**Example**

```recurloop
include "src/main.rl"
```

## Syntax

```recurloop
<path:string>
```

## Example

```recurloop
include "helpers.rl"
```

## Arguments

- ** ** — 
- **:** — 
- **path** — Quoted path, relative to the including file.
