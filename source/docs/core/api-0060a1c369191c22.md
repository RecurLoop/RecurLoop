```recurloop
let name = phrase {
    field = value
    ...
}
```

Builds a phrase descriptor. Fields select its type, prototype, action, dictionary, payload and metadata. References use `<path>`; flags use `true` or `false`.

**Example**

```recurloop
let branch = phrase {
    prototype = <if>
    docs = "Run a block when its condition is true."
}
```
