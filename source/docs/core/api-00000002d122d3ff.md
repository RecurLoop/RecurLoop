```recurloop
abi name(property(...), ...)
```

Defines a calling convention. Select it on a function declaration with `abi name`. Built-ins include `sysv-amd64`, `microsoft-x64`, `cdecl-x86`, `stdcall-x86` and `fastcall-x86`.

**Example**

```recurloop
extern puts(text:u8*) -> i32 abi sysv-amd64
```
