Print a value followed by a newline.

```recurloop
print expression
```

Formats a runtime expression and writes it followed by a newline.

**Example**

```recurloop
print "Answer: " + str(42)
```

## Syntax

```recurloop
<value:expr>
```

## Example

```recurloop
print 20 + 22
```

## Arguments

- ** ** — 
- **:** — 
- **value** — An expression to display.
