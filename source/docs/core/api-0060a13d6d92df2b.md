Fail when the condition is false.

```recurloop
assert condition
```

Checks a runtime condition and reports an error if it is false.

**Example**

```recurloop
assert answer == 42
```

## Syntax

```recurloop
<condition:expr>
```

## Example

```recurloop
assert 20 + 22 == 42
```

## Arguments

- ** ** — 
- **:** — 
- **condition** — True means success; false stops execution with a diagnostic.
