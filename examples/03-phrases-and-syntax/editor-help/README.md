# Editor help

Run `recurloop main.rl`: it prints `42` and `hello`.

In a VS Code project that includes this file, complete `show ` or `display `.
Both offer names from `Values`, with the argument's short explanation. Hover
shows the effect and example. **RecurLoop: Help** finds the phrase by its
summary or tags and inserts its snippet. `display` inherits the contract.

The [author guide](../../../docs/editor-help.md) explains the optional fields.
